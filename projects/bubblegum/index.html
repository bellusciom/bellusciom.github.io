Generalized Bubblegum Proof

In the generalized bubblegum elimination circle, the chooser can always arrange to be chosen again — without ever having to eliminate themselves.

The game

$n$ players stand in a circle, and one is chosen to pick a number $K$. The player $K$ clockwise positions away from the chosen player is then eliminated, and the player $B$ clockwise positions away from the eliminated player is then chosen to pick the next number.

Question. For all $n \in \mathbb{N}$, can the chosen player pick a $K$ such that they will once again be chosen on the next turn?

Setting up the loop condition

In order for the chosen player to be chosen again, either $K + B$ positions away is one full loop,

$$K + B = n,$$

or it makes several full loops,

$$K + B = n + A(n-1), \qquad A \in \mathbb{N}$$

(after the elimination only $n-1$ players remain, so each additional loop has length $n-1$).

Claim. There is never a case where the chosen player must eliminate themselves in order for one full loop or several full loops to be made.

Proof

For $B \in \mathbb{N}^{+}$ and $n > 1$, there exists $A \in \mathbb{N}$ such that

$$(A+1)(n-1) \;>\; B-1 \;\geq\; A(n-1).$$

Negating and subtracting $1$,

$$-(A+1)(n-1) - 1 \;<\; -B \;\leq\; -A(n-1) - 1,$$

then adding $n$,

$$n - (A+1)(n-1) - 1 \;<\; n - B \;\leq\; n - A(n-1) - 1,$$

and adding $A(n-1)$ throughout,

$$n + A(n-1) - (A+1)(n-1) - 1 \;<\; n - B + A(n-1) \;\leq\; n - A(n-1) - 1 + A(n-1)$$

$$\Rightarrow\; n - (n-1) - 1 \;<\; n - B + A(n-1) \;\leq\; n - 1$$

$$\Rightarrow\; 0 \;<\; n - B + A(n-1) \;\leq\; n - 1.$$

Take $K = n - B + A(n-1)$. Then

$$K + B = n + A(n-1), \qquad A \in \mathbb{N}. \quad$$$\blacksquare$

Since $0 < K \leq n - 1$, this $K$ is a legal pick that eliminates a player other than the chooser — so the chooser can always return the selection to themselves without self-elimination.
