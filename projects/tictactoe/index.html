Tic-Tac-Toe: $n \times n$ is Unwinnable

A complete analysis of the $3 \times 3$ game, extended to every larger board by induction.

This argument concerns generalized tic-tac-toe: $n$ in a row on an $n \times n$ board, with X moving first. The $3 \times 3$ base case is settled by a direct case analysis over X's openings, phrased in terms of the win-condition domains that remain open as the game progresses; a companion argument shows O cannot win either, and two lemmas bound the earliest turn on which any win can occur. An induction step then extends the result to every larger board: the opposing player can always deny a win, so the game is decidably unwinnable.

Notation

Cells are numbered $1$ through $9$:

123
456
789

We denote the win-condition domains as follows: $\ell_1, \ell_2, \ell_3$ are the three rows (top to bottom), $h_1, h_2, h_3$ the three columns (left to right), and $d_1 = \{3,5,7\}$, $d_2 = \{1,5,9\}$ the two diagonals, so that $$\Lambda \;=\; \{\ell_1, \ell_2, \ell_3,\; h_1, h_2, h_3,\; d_1, d_2\}.$$

  • Let $X_t$ be the placement of X on turn $t$, and $O_t$ be defined similarly.
  • Let $\Lambda_t^x$ be the open domains for X at turn $t$.
  • Let ${}_x\Lambda_t^n$ be the open domains with $n$ X's at turn $t$.
Note. A domain is open for a player while it contains none of the opponent's marks — that is, while it can still be completed. Turns are counted by single moves, so $X_1, O_2, X_3, \ldots, X_9$; the analogous symbols $\Lambda_t^o$ and ${}_o\Lambda_t^n$ are used for O.

The $3 \times 3$ game

Theorem 1. If O plays optimally, X cannot win $3 \times 3$ tic-tac-toe.
Proof.

Case I: $X_1 = 1$. Then take $O_2 = 5$.

Case I.I: $X_3 = 2, 6$. Then take $O_4 = 3$.

$$\Rightarrow\; {}_x\Lambda_4^2 = \emptyset,\quad {}_x\Lambda_4^1 = \{h_1\},\quad \Lambda_4^x = \{h_1, \ell_3\}$$ $$\Rightarrow\; {}_x\Lambda_6^2 = \emptyset,\quad \lvert \Lambda_6^x \rvert < 2$$

Similarly for $X_3 = 4, 8$.

Case I.II: $X_3 = 3, 9$. Then take $O_4 = 2 \Rightarrow X_5 = 8$

$$\Rightarrow\; O_6 = 7 \;\Rightarrow\; \Lambda_6^x = \{h_3\},\quad {}_x\Lambda_6^2 = \emptyset$$

Similarly for $X_3 = 7$.

WLOG, this covers $X_1 = 3, 7, 9$.

Case II: $X_1 = 2$. Then take $O_2 = 5$.

Case II.I: $X_3 = 1, 3$. This is equivalent to Case I.I.

Case II.II: $X_3 = 4, 8$. Take $O_4 = 1 \Rightarrow X_5 = 9$, then take $O_6 = 7$

$$\Rightarrow\; {}_x\Lambda_6^2 = \emptyset,\quad \Lambda_6^x = \{h_3\}$$

Similarly for $X_3 = 6$.

Case II.III: $X_3 = 7$. Take $O_4 = 1 \Rightarrow X_5 = 9 \Rightarrow O_6 = 8$

$$\Rightarrow\; {}_x\Lambda_6^2 = \emptyset,\quad \Lambda_6^x = \{h_3\}$$

Similarly for $X_3 = 9$.

WLOG, this covers $X_1 = 4, 6, 8$.

Case III: $X_1 = 5$. Take $O_2 = 1$.

Case III.I: $X_3 = 2$.

$$\Rightarrow\; O_4 = 8,\quad {}_x\Lambda_4^2 = \emptyset,\quad {}_x\Lambda_4^1 = \{d_1, \ell_2\},\quad \Lambda_4^x = \{d_1, \ell_2, h_3\}$$

Case III.I.I: $X_5 = 7, 9$. Take $O_6 = 3$

$$\Rightarrow\; {}_x\Lambda_6^2 = \emptyset,\quad \lvert \Lambda_6^x \rvert < 2$$

Case III.I.II: $X_5 = 4$

$$\Rightarrow\; O_6 = 6 \;\Rightarrow\; {}_x\Lambda_6^2 = \emptyset,\quad \lvert \Lambda_6^x \rvert < 2$$

Case III.I.III: $X_5 = 6$

$$\Rightarrow\; O_6 = 4 \;\Rightarrow\; X_7 = 7 \;\Rightarrow\; O_8 = 3 \;\Rightarrow\; \Lambda_8^x = \emptyset$$

Case III.I.IV: $X_5 = 3$

$$\Rightarrow\; O_6 = 7 \;\Rightarrow\; X_7 = 4 \;\Rightarrow\; O_8 = 6 \;\Rightarrow\; \Lambda_8^x = \emptyset$$

Similarly for $X_3 = 4$.

Case III.II: $X_3 = 3$

$$\Rightarrow\; O_4 = 7 \;\Rightarrow\; X_5 = 4 \;\Rightarrow\; O_6 = 6 \;\Rightarrow\; {}_x\Lambda_6^2 = \emptyset,\quad \lvert \Lambda_6^x \rvert < 2$$

Similarly for $X_3 = 7$.

Case III.III: $X_3 = 6$

$$\Rightarrow\; O_4 = 4 \;\Rightarrow\; X_5 = 7 \;\Rightarrow\; O_6 = 3 \;\Rightarrow\; X_7 = 2 \;\Rightarrow\; O_8 = 8 \;\Rightarrow\; \Lambda_8^x = \emptyset$$

Similarly for $X_3 = 8$.

Case III.IV: $X_3 = 9$. Take $O_4 = 7 \Rightarrow X_5 = 4 \Rightarrow O_6 = 6$

$$\Rightarrow\; {}_x\Lambda_6^2 = \emptyset,\quad \lvert \Lambda_6^x \rvert < 2$$

Therefore, $3 \times 3$ tic-tac-toe is decidably unwinnable for X. $\blacksquare$

Theorem 2. If X plays optimally, O cannot win $3 \times 3$ tic-tac-toe.
Proof. Let $X_1 = 5$, then let $X_3 = 1, 3, 7, 9$ $$\Rightarrow\; \lvert \Lambda_3^o \rvert = 2,\quad \lvert {}_o\Lambda_3^1 \rvert \le 2 \;\Rightarrow\; {}_o\Lambda_5^1 = \emptyset,\quad \lvert \Lambda_5^o \rvert < 2. \quad$$ $\blacksquare$

The case analyses above terminate once the open-domain counts are pinned down; the following lemmas are what make those terminations conclusive.

Lemma 1. For $\alpha \in \{X, O\}$ to win on turn $t^*$, $\lvert {}_\alpha\Lambda_{t^*-2}^2 \rvert \ge 2$.
Proof. If $\lvert {}_\alpha\Lambda_{t^*-2}^2 \rvert = 1$, then $\beta \in \{X, O\} \setminus \alpha$ can play such that ${}_\alpha\Lambda_{t^*-1}^2 = \emptyset$, thus $\alpha$ cannot win on turn $t^*$. $\blacksquare$
Lemma 2. X cannot win before turn 7, O before turn 8.
Proof. Suppose X wins on turn $t^*$. Then $\lvert {}_x\Lambda_{t^*-2}^2 \rvert \ge 2$. Because each winnable domain overlaps at most once with each other one, at least 3 X's must be played on turn $t^* - 2$ $$\Rightarrow\; t^* - 2 \ge 5 \;\Rightarrow\; t^* \ge 7.$$ Similarly for O. $\blacksquare$

Induction step

Proof. Suppose $(n-1) \times (n-1)$ tic-tac-toe is decidably unwinnable. Then for an $n \times n$ grid, take some $(n-1) \times (n-1)$ subgrid.

If X plays within that subgrid, respond as if playing $(n-1) \times (n-1)$ tic-tac-toe.

If X plays outside the subgrid, play an O to block one of the two win conditions independent of the subgrid, in alternating fashion.

Then, because $(n-1) \times (n-1)$ tic-tac-toe is decidably unwinnable, there will not be any $n-1$ consecutive X's in the subgrid.

But with every move outside of the subgrid, one of the remaining two win conditions was blocked. So X cannot win outside the subgrid.

Thus, $n \times n$ tic-tac-toe is decidably unwinnable. $\blacksquare$
